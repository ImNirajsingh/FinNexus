# Bank Statement Analyzer

This project structures a bank statement analysis workflow with preprocessing, feature engineering, analytics, anomaly detection, and RAG-based exploration.

## Project layout

- `data/raw/` keeps the original source CSV.
- `data/processed/` stores cleaned and derived datasets.
- `notebooks/` contains analysis and modeling notebooks.
- `src/` holds reusable Python modules.
- `app/` contains the Streamlit dashboard.

## Getting started

1. Install dependencies from `requirements.txt`.
2. Place the raw statement CSV in `data/raw/bank_statement.csv`.
3. Use the notebooks in order for preprocessing and analysis.
4. Run the app with Streamlit.
